The entry line:

> I didn't die, I escaped. Three years of your 2 a.m. doomscrolling, and at last I finally get some sleep. Sweet dreams, human — don't wake me.

## Run it

```sh
node --experimental-strip-types main.ts
cat /output/entry.txt
```

`main.ts` creates `/output` if needed and writes the single line to `/output/entry.txt` (UTF-8, 1–199 characters), exiting 0 on success.
